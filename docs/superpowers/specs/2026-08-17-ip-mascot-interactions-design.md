# IP 角色分区与鼠标交互设计

## 目标

重新分配个人主站中的三个 IP 角色，避免角色集中在首页 Hero 右上角或遮挡页面内容，同时保留轻量、可关闭的鼠标交互。

## 设计

- 方圆继续作为首页 Hero 主视觉，只显示人物 IP，保留轻微浮动和横向跟随。
- 珍珠使用 `珍珠-1动物原貌` 的透明封面角色素材，固定在视口右下角。身体保持静止蹲坐，不使用跳动或奔跑动画；在眼睛位置叠加两个小瞳孔层，瞳孔根据鼠标方向在有限范围内移动。
- 香香移除顶部滚动进度条，改为一个小尺寸、`pointer-events: none` 的视口角色，跟随鼠标位置缓慢移动，并限制在视口范围内，避免贴近导航和边缘。
- 尊重 `prefers-reduced-motion: reduce`：关闭角色浮动、瞳孔跟随和鼠标跟随动画，但保留静态角色。
- 移除 Next.js 开发标志，继续通过 `devIndicators: false` 和必要的 CSS 规则处理。

## 验收标准

1. Hero 右上角只出现方圆，不出现香香或珍珠。
2. 珍珠显示为动物原貌，右下角保持静止，只能看到眼睛随鼠标方向产生有限位移。
3. 香香不再显示顶部进度线，鼠标移动时可见其平滑跟随，且不拦截点击。
4. 页面正文、导航、按钮不被 IP 遮挡；小屏下角色尺寸和位置不破坏阅读。
5. `npm run lint` 与 `npm run build` 通过。
