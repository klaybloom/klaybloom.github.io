今天的 AIHOT 日报没有 lead，但信息密度很高。最值得中文 AI 创业者、开发者和产品人看的，不是单条模型发布，而是一组同时出现的变化：

模型更会自己做事，工具协议正在变成入口，Agent 开发框架开始强调可靠性，连产品演示视频都可以交给智能体自动录制。

这意味着一件事：AI Agent 正在从“能聊、能写、能出方案”，走向“能接工具、能执行任务、能留下证据”的阶段。

## 1. Claude Sonnet 5：Agent 能力开始按成本核算

AIHOT 今天的模型版块里，最重要的是 Claude Sonnet 5。日报摘要显示，它具备计划、浏览器和终端工具使用能力，可自主运行；性能接近 Opus 4.8，但价格更低。

价格信息很关键：2026 年 8 月 31 日前，输入 token 为 2 美元/百万，输出 token 为 10 美元/百万；之后恢复到输入 3 美元/百万、输出 15 美元/百万。

这对开发者不是“又一个更聪明的模型”这么简单。

以前很多 Agent demo 看起来很强，但一旦放到真实工作流里，成本、延迟和失败后的返工会立刻变成问题。Sonnet 5 这种定位，真正的看点在于：它把接近旗舰模型的工具使用能力，放到更容易试算 ROI 的价格层。

如果你正在做代码助手、运营助手、资料分析助手、客服质检助手，接下来判断模型是否可用，不应该只看 benchmark。更实际的指标是：

- 一次完整任务要调用多少轮；
- 出错后是否能自己修正；
- 是否能稳定使用浏览器、终端、文件系统和业务 API；
- 同样任务下，人工复核时间是否真的减少。

## 2. X MCP：实时信息源正在变成智能体接口

产品版块里，X 发布 hosted X MCP 也值得看。AIHOT 摘要显示，AI 智能体可以通过 MCP 协议直接调用 X API 获取实时信息，支持 Grok、Cursor 等工具；个人优惠价是每次调用 0.01 美元。

这件事的意义不是“可以让 AI 读 X 了”。真正的变化是，内容平台开始把自己包装成 Agent 可以直接调用的工具。

对产品人来说，这会影响信息类产品的形态。过去你做监控、舆情、选题、竞品追踪，常见路径是爬虫、RSS、人工筛选、再接模型总结。MCP 化之后，平台可能直接变成智能体工具箱里的一个节点。

这会带来两个机会：

- 垂直场景可以更快接入实时信息，比如创投线索、开发者动态、海外产品反馈；
- 信息产品的竞争点会从“能不能抓到数据”，转向“能不能把数据变成稳定动作”。

同时也有一个现实问题：一旦调用变成按次计费，Agent 的工具使用就必须有预算意识。会不会查、查几次、失败后是否重试、要不要缓存，都不再是工程细节，而是产品成本。

## 3. ADK Go 2.0：多智能体开始补工程短板

Google Developers Blog 的 ADK Go 2.0，表面看是框架更新，实质是在补多智能体应用的工程短板。

AIHOT 摘要里提到几个关键词：基于图的工作流引擎、人工参与循环、动态编排、指数退避重试、统一执行模型、遥测与状态持久化。

这些词说明多智能体开发已经过了“把几个 Agent 串起来”的阶段。真实业务更需要的是：

- 哪一步可以自动执行；
- 哪一步必须等人确认；
- 哪一步失败后可以重试；
- 状态如何保存；
- 日志和遥测如何追踪；
- 复杂流程如何被测试和复盘。

这也是今天很多 Agent 产品的分水岭。演示里，Agent 能完成一个任务就很惊艳；业务里，Agent 必须能解释为什么这么做、失败在哪里、下次如何避免同类问题。

所以，开发者看 ADK Go 2.0，不一定要马上换框架。更应该借它反推自己的 Agent 架构：有没有显式流程图？有没有人工确认点？有没有状态持久化？有没有可观察性？

## 4. shot-scraper video：AI 也开始生成“工作证据”

Simon Willison 的 shot-scraper video 更新看起来很小，但它指向一个很实用的方向：让 AI 智能体录制工作演示视频。

AIHOT 摘要显示，shot-scraper 1.10 新增 video 命令，可以通过 storyboard.yml 定义操作步骤，并利用 Playwright 录制浏览器视频。Simon 特别强调，`--help` 输出写得足够详细，编码 Agent 就能直接利用该命令生成演示视频。

这对开发团队很有价值。

现在 AI 写代码已经不稀奇，难的是怎么证明它真的改对了。截图、测试日志、页面录屏，都会变成 Agent 工作结果的一部分。未来一个靠谱的编码 Agent，交付物可能不只是 diff，还包括：

- 测试命令和结果；
- 页面截图；
- 操作录屏；
- 失败用例；
- 回滚说明；
- 人工复核清单。

这也是开发者工具的新机会。谁能把“做事”和“证明做完”放在同一个工作流里，谁就更容易进入团队的真实开发流程。

## 今天可以做的 3 个判断

第一，模型发布要看“可执行性”，不只看参数和榜单。Claude Sonnet 5 的重点在于工具使用、价格和 Agent 场景。

第二，MCP 正在成为平台接入 Agent 的通用语言。X MCP 这类产品会让实时信息、业务系统和开发工具更容易被模型调用。

第三，Agent 产品必须把验证做进流程。ADK Go 2.0 和 shot-scraper video 都在说明同一件事：没有状态、重试、人工确认和证据输出，Agent 很难从演示走到生产。

如果你今天要立刻做点什么，可以从一个小任务开始：选一个团队里重复发生、结果容易验证的流程，把它改成“模型负责执行，人负责确认，系统负责留证据”。

这比再做一个聊天入口更接近下一阶段的产品形态。
